This is a starbie project by hacklife. A starbie is meant to be similar to a tamogatchi.
Using KiCad's Schematic editor, I created circuits on the XIAO ESP32C3 inwhich the starbie can move via buttons and detect the enviornment with an enviornment sensor.
This was then connected to the PCB and I chose a rounded heart shape as my base. 
In Arduino, I replicated the code given using my own wire managment and my starbie can draw hearts as well as little sparkles.
